# Keyboard reference

Generated by `mailtui --keybindings`.

| Key | Action |
|---|---|
| `Ctrl+a` | Open or resume the optional mail assistant · :ai |
| `Ctrl+s` | Save attachments / save calendar or contact form |
| `:` | Command mode · ↑/↓ history |
| `/` | Mail search / calendar or contact filter |
| `?` | Open this keyboard reference |
| `Esc` | Cancel / clear filter / previous view |
| `q` | Back; quit at root |
| `↓` | Next tree row / scroll down |
| `↑` | Previous tree row / scroll up |
| `PgDn` | Page down |
| `PgUp` | Page up |
| `Ctrl+d` | Delete mail/calendar/contact item · confirmation |
| `Ctrl+c` | Press twice within 3 seconds to quit |
| `Enter` | Fold/read mail; view calendar event or contact |
| `Space` | Toggle selected message (never an account or folder) |
| `a` | Select all visible loaded messages |
| `Shift+n` | Sort messages by subject within each folder |
| `Shift+a` | Sort messages by date within each folder |
| `Shift+p` | Sort account branches (all-account scope) |
| `Shift+s` | Sort messages by status within each folder |
| `s` | Cycle message sort: date/from/subject/size |
| `i` | Mark messages read |
| `u` | Use account / mark messages unread |
| `m` | Move messages · fuzzy destination picker |
| `y` | Copy messages to folder |
| `h` | Open HTML · remote images blocked |
| `H` | Open HTML · remote images enabled |
| `c` | Compose mail / create event or contact · editing controls in form |
| `e` | Edit selected calendar/contact item |
| `n` | Create directory / event / contact |
| `r` | Explain reply capability |
| `R` | Explain reply-all capability |
| `f` | Explain forward capability |
| `0` | Mail view · all mail accounts |
| `1` | Calendar view when configured |
| `2` | Contacts view when configured |
